# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Se você encontrar uma vulnerabilidade, por favor:
1. **Não** abra uma issue pública
2. Envie um email para o mantenedor
3. Descreva o problema em detalhes
4. Aguarde a resposta em até 48h

## Security Features

ShieldScan foi desenvolvido para **detectar** vulnerabilidades, não introduzi-las. O código é auditado regularmente.
